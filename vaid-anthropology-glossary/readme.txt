Admin-managed Anthropology & UPSC glossary with a Figma-faithful public Hub (hero, search, A-Z navigation, term cards).

== Description ==

VAID Anthropology Glossary is a pilot plugin providing:

* A `vaid_glossary_term` custom post type for admin/CMS-managed glossary entries (not individually public in this version).
* A CSV import (dry-run + confirm + rollback) and export workflow.
* A single public Glossary Hub page — hero, search field, A-Z navigation, and term cards — matching the verified Figma design (Glossary /D `365:4538`, Glossary /M `453:8439`).
* Client-side search and A-Z filtering with no network requests.

See BUILD-REPORT.md in the repository for full architecture notes, known limitations, and installation/test steps.
